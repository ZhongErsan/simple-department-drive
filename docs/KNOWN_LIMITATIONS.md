# 已知简化点

这份代码用于第一遍学习，不应直接当作生产系统。

## 并发同名

当前是“先查询、后插入”，并发时可能同时通过。第二遍应增加数据库唯一约束，并处理唯一键异常。

## 文件与数据库事务

当前流程：

```text
写磁盘
→ 插入数据库
→ 数据库方法内异常时删除磁盘
```

如果数据库异常发生在 Spring 最终提交阶段，方法内 catch 可能捕获不到。第二遍应注册事务完成回调，并增加持久化清理重试。

## MIME

当前只检查扩展名，不检查真实内容。第二遍使用 Apache Tika，并建立扩展名到 MIME 的允许映射。

## 删除

当前只把数据库状态改成 `DELETED`，不会释放磁盘。第二遍增加回收站、永久删除和清理任务。

## 用户返回对象

当前 Controller 把实体中的密码设为 null 后返回。第二遍应使用专门的 UserVO。

## 查询效率

文件列表逐条查询上传者姓名，存在 N+1。第二遍使用 JOIN、自定义 SQL 或批量查询。

## 配额和日志

第一遍没有个人、部门、系统配额，也没有操作日志。
